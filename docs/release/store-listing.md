# Store Listing Draft

## Product Positioning

`AppLimiter` helps you control how much time you spend in selected apps. Set a daily limit, monitor usage, and optionally block an app when the limit is reached.

## Short Description

Limit daily app usage and block apps after your time is up.

## Full Description

Take control of your screen time.

`AppLimiter` lets you set daily time limits for the apps you choose. See today's usage, configure hours and minutes for each app, and optionally enable monitoring so that an app is closed when its daily limit is exhausted.

### What it does well

- Browse installed apps and search quickly
- Set per-app daily limits in hours and minutes
- Monitor usage against your limits
- Optionally block apps after the limit is reached
- Light / dark / system appearance
- In-app feedback contact for support

### Best for

- Reducing distracting app usage
- Focus sessions and study time
- Parents and self-control routines
- Anyone who wants simple local limits without an account

## Play Review Notes

> AppLimiter is a local digital-wellbeing tool. It needs Usage Access to measure daily app usage, permission to list installed apps so the user can choose limits, and an Accessibility service only to return the user to the home screen when a limited app is opened after its daily limit is exhausted. No account is required. Limits and preferences are stored locally. The Accessibility service is not used to read passwords, messages, or payment data and is not used for ads or analytics.
